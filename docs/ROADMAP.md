# Roadmap InteractiveFoodMenu

## Ближайший этап — управление оформлением

- [x] Единый Backend Hub для управления точками.
- [x] Выбор логотипа, положения, отступа и масштаба.
- [x] Переключатель показа логотипа на экране меню.
- [x] Быстрые переходы из хаба к экрану меню и Staff для каждой точки.
- [ ] Превью оформления точки прямо в хабе.
- [ ] Единые компоненты форм и сообщений для Hub и Staff.

## Меню и отображение

- [ ] Автоматический масштаб меню в зависимости от количества доступных позиций.
- [ ] Автоматическое перемещение недоступных позиций в конец списка.
- [ ] Переключатель «Скрывать недоступные позиции» в настройках точки.
- [ ] Сохранение выбранного режима сортировки и отображения в оформлении точки.
- [ ] Тесты пагинации, автоподбора масштаба и сортировки доступности.

## Надёжность и производительность

- [ ] Уменьшить частоту фонового обновления меню и добавить адаптивный backoff при потере сети.
- [ ] Добавить условные запросы/версию меню, чтобы не загружать неизменившиеся данные.
- [ ] Настроить `_APP_WORKER_PER_CORE` и usage-статистику Appwrite под фактическую нагрузку.
- [ ] Добавить мониторинг CPU, RAM, перезапусков и ошибок Redis/PostgreSQL.
- [ ] Описать регламент резервного копирования Appwrite.

## Деплой и масштабирование

- [ ] Автоматическая сборка и публикация Docker-образов.
- [ ] Проверка миграций Appwrite перед каждым релизом.
- [ ] Отдельные staging и production окружения.
- [ ] Горизонтальное масштабирование API при появлении нескольких площадок.
