# Архитектура InteractiveFoodMenu

- [Векторная UML диаграмма компонентов](architecture.svg) — вручную выровненная схема со слоями клиентов, API, политики доступа, модулей и провайдеров хранения.
- [PNG для Word](architecture.png).
- [Редактируемый исходник PlantUML](architecture.puml) — семантически та же структура; автоматическое расположение отличается от SVG.

Все серверные прикладные компоненты относятся к одному процессу `backend-api`. Redis ограничивает запросы и не заменяет PostgreSQL LISTEN/NOTIFY. Appwrite и PostgreSQL — альтернативные провайдеры, а не одновременно действующие источники.

Новый контур ВКР проверен на локальном PostgreSQL-стенде. Наличие Appwrite-адаптера на схеме отражает поддержку в коде; его новые операции требуют отдельной проверки на настоящем Appwrite.

Описание модулей, модель данных и права: [реализация ВКР](../VKR_IMPLEMENTATION.md). Результаты: [протокол](../stand-results/2026-11-16/PROTOCOL.md).
