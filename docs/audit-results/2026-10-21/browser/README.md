# Браузерная и Android-проверка

21.10.2026, кандидат на отдельном Appwrite. Playwright Chromium, 390×844,
1366×768 и 1920×1080. Это проверка современным браузерным движком, а не физического
старого телевизора.

- Два DOM-click при задержке stock POST на 800 мс дали один запрос и 100000 → 100001.
- Второй кабинет получил 100001 без ручного обновления. Мобильная форма 390 px
  не имеет горизонтального переполнения: `staff-mobile-stock.png`.
- Серверное ТВ сохранило меню при ошибке сети, показало предупреждение и восстановило
  связь после снятия отказа: `tv-offline.png`, `tv-1366.png`, `tv-1920.png`.
- Современное меню и React legacy отрисованы. В legacy использован whatwg-fetch
  поверх XHR: `react-xhr-1366.png`. Изначальное ожидание `.display-shell` было ошибкой
  скрипта: корень legacy — `.tv-screen`. Это не дефект приложения.
- `modern-1920.png` снят во время входной анимации и не используется как доказательство
  окончательного расположения строк. Проверка прямой API XHR-ветки не выполнена: работа остановлена по просьбе пользователя.

## Android-эмулятор: локальный HTTP mock

Android API 35 / arm64-v8a, 1080×2400. Код приложения из кандидата, отдельная
приватная копия с debug-настройкой тестового HTTP и адресом 10.0.2.2:28093.
Основной APK и рабочая сетевая политика не менялись. Эти результаты не являются
проверкой Android на реальном Appwrite либо физическом устройстве.

Подтверждены 1 → 0 → 1, блокировка минуса при нуле, абсолютный остаток 7,
два импорта одного CSV с единственным созданием новой позиции и сохранением старой
цены, изменение цены с сохранением количества. При обычном редактировании tracked
позиции PATCH содержит только name/priceMinor/sortOrder. При потере ответа после
применения +1 отправлен один POST, сервер хранит 2 вместо 1; приложение перечитало
2 и предупредило о неизвестном результате, автоматического повторения не было.
После остановки mock последнее меню осталось видимым; кнопка «Повторить» восстановила
связь. Снимки `android-*-mock.png`, безопасный журнал без тел/заголовков запросов —
`../evidence/android-mock-actions.jsonl`. Основные контрольные значения — validation.json.
